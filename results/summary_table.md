# Open Decision Benchmarks: Consolidated Evaluation Summary

本リポジトリは、型付き判断モデル（System 1 Decision Models）およびオープン基盤モデルの判断性能、確率較正（Calibration）、長文契約書耐性、語用論的論理トラップ耐性を多角的に測定した実機ベンチマーク記録です。

---

## 1. モデル構成と検証環境

- **検証環境**: NVIDIA GeForce RTX 3090 (24GB VRAM) / Windows 11 & WSL2 Ubuntu 24.04 / CUDA 12.8
- **評価対象モデル**:
  1. **Jev (Cloud API)**: TypeSafe AI による判断特化型クラウドAPI（8B相当 / `jev-1.13.0`）
  2. **Lev (Local 8B)**: TypeSafe AI オープンモデル `interfaze-ai/lev`（Full Attention Decision Head）
  3. **Jeff-0.8B (Local 0.8B)**: `firelex/jeff-0.8b`（軽量Cross-Encoder型判断モデル）
  4. **Kev-4B (Local 4B)**: `jaredpalmer/kev-4b`（Gated DeltaNet 線形アテンション判断モデル）
  5. **Qwen3.5-4B (Local SGLang)**: 基盤モデル `Qwen/Qwen3.5-4B` + RadixAttention KVキャッシュ
  6. **CLM-8B (Local 8B)**: Contrastive Language Model（Hazy Research / Qwen3-8B Dual-Encoder）

- **否定疑問文の応答論理**: 日本語「届いていませんか？→はい（届いていない）」および英語「Didn't you receive?→No（did not receive）」の真偽反転は全モデルが正解。
- **表層単語バイアスの克服**: 「エラー、例外、クラッシュ」が頻出する文章でも、全モデルが「防御機構（正常）」と判定。
- **境界線となった難所**: 「原則禁止→条件付き許可→例外免除」の多重入れ子例外において、Kev-4B、Qwen3.5、Jeff、CLMがつまずき、LevとJevのみが正しく適法と判定。

## 6. CLM-8B Action Caching 実機検証（有効領域と構造的制約）

CLM-8Bの「Action Caching（選択肢埋め込みの事前計算・キャッシュ機構）」について、5つのシナリオで検証しました。

### ① 有効性が確認されたシナリオ
1. **固定選択肢タスク（massive-en-US 60意図分類）**:
   - Cold推論: 0.0%（266.5 ms / 辞書文字列ノイズ）
   - Action Cached + 入力整形: **44.0%（98.1 ms / 2.72倍向上）**
2. **高頻度Tickポリシー制御（Rocket League 3v3 tick 12アクション）**:
   - Cold推論: 808.4 ms
   - Action Cached: **115.6 ms（6.99倍向上）**
   - 状態エンコード1回 + 12ベクトルの内積計算により、リアルタイム推論ループが可能。
3. **言明型の能動的リフレーミング（童話境界テスト 13ケース）**:
   - 旧プロンプト（疑問文フラグ）: 30.8%（4/13正解 / 単語共起に牽引）
   - 行動言明リフレーミング + キャッシュ: **84.6%（11/13正解）**

### ② 構造的制約が確認されたシナリオ
1. **三値論理・確信度の偏向（Tri-State Collapse）**:
   - 不確実・グレーゾーン（Uncertain）の平均確率が **11.41%** に圧縮。
   - スケーリング係数（$\alpha \approx 100$）によるSoftmax鋭角化により、85.89%が「Impossible」に偏向し、適切な保留判断が困難。
2. **長文情報抽出（Phase 2 長文契約書 15問）**:
   - 正解率: **40.0%（6/15問）**
   - 平均レイテンシ: 0.78 秒
   - Bi-Encoderの文表現プーリングにより、数千トークン中に散在する局所条項が希釈され、15問中13問が「False」と判定。
