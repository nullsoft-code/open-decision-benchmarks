# Benchmark Summary: Boundary, Calibration & Decision Contrast (4 Models)

本ベンチマークでは、以下の4モデルについて、同一のテストセット（13ケース童話境界テスト、三値論理テスト、OOD未知知識テスト）を用いて比較検証を行いました：
1. **Jev (Cloud API)**: プロプライエタリな判断特化モデル（8B相当）
2. **Kev-4B (WSL2 / DeltaNet)**: オープンな判断特化モデル（Decision Head方式）
3. **Qwen3.5-4B (llama-server GGUF)**: 汎用生成モデルのLogits直接抽出方式
4. **CLM-8B (WSL2/Win PyTorch)**: Contrastive LM（Qwen3-8B + 3層MLP射影ヘッド方式 / Hazy Research）
